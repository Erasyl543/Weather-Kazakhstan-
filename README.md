Weather KZ

ETL-проект для сбора, обработки и анализа данных о погоде и качестве воздуха в городах Казахстана.

Проект получает данные из Open-Meteo API за последние 90 дней, обрабатывает их с помощью Python, сохраняет в PostgreSQL и визуализирует в Power BI.

О проекте

В проекте собираются почасовые данные для 10 городов Казахстана:

Алматы, Астана, Шымкент, Караганда, Актобе, Тараз, Павлодар, Усть-Каменогорск, Костанай, Кызылорда.

Собираемые показатели:

температура;
влажность;
скорость ветра;
PM10;
PM2.5;
угарный газ (CO);
диоксид азота (NO₂).

Анализ и визуализация

Полученные данные очищаются, приводятся к нужному формату, после чего сохраняются в PostgreSQL.

Анализ и визуализация

Для анализа данных создан дашборд в Power BI.

В рамках проекта были исследованы следующие вопросы:

В каких городах уровень загрязнения воздуха выше?
Как изменяется PM2.5 во времени?
Как отличается средняя температура между городами?
Есть ли связь между температурой и загрязнением воздуха?
Как меняется уровень загрязнения в зависимости от времени года?
В каких городах наблюдаются наиболее высокие уровни загрязнения?

В Power BI использованы карта, графики динамики, сравнение городов, анализ взаимосвязей и фильтры.

Запуск

Установить зависимости:

pip install -r requirements.txt

Создать базу данных PostgreSQL weather_kz и указать данные подключения в .env:

DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
DB_NAME=weather_kz

Запустить проект:

python src/main.py

После запуска данные будут загружены в PostgreSQL в таблицы:

weather_hourly
air_quality_hourly
