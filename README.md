
ETL-проект для сбора, обработки и анализа данных о погоде и качестве воздуха в городах Казахстана.

Проект автоматически получает почасовые данные из **Open-Meteo API**, обрабатывает их с помощью **Python / Pandas**, сохраняет в **PostgreSQL** и предоставляет аналитический дашборд в **Power BI**.

---

## О проекте

**Weather KZ** — практический ETL и Data Analytics проект, построенный по принципу:

```text
Open-Meteo API
      ↓
Сбор данных
      ↓
Python / Pandas
      ↓
Очистка и обработка
      ↓
PostgreSQL
      ↓
Power BI
      ↓
Анализ и визуализация
```

Проект предназначен для анализа погодных условий и качества воздуха в городах Казахстана.

---

## География

Данные собираются для 10 городов Казахстана:

- Алматы
- Астана

- Караганда
- Актобе
- Тараз
- Павлодар

## Данные

### Погодные показатели

- Температура
- Относительная влажность
- Скорость ветра

### Качество воздуха

- PM10
- PM2.5
- CO — угарный газ
- NO₂ — диоксид азота

Данные собираются с **почасовой детализацией**.

Проект загружает исторические данные за последние **90 дней** и поддерживает дальнейшее обновление данных.

---

## ETL-процесс

### 1. Extract — получение данных

Python отправляет запросы к **Open-Meteo API** и получает данные о погоде и качестве воздуха для выбранных городов.

### 2. Transform — обработка

Полученные данные обрабатываются с помощью **Pandas**:

- проверяются типы данных;
- обрабатываются временные значения;
- данные приводятся к единому формату;
- подготавливаются показатели для загрузки в базу данных.

### 3. Load — загрузка

Подготовленные данные сохраняются в **PostgreSQL**.

Основные таблицы:

```text
weather_hourly
air_quality_hourly
```

## Аналитика и визуализация

Для анализа создан интерактивный **Power BI dashboard**.

Проект позволяет исследовать следующие вопросы:

- В каких городах уровень загрязнения воздуха выше?
- Как изменяется PM2.5 во времени?
- Как отличается средняя температура между городами?
- Есть ли взаимосвязь между температурой и загрязнением воздуха?
- Как меняется качество воздуха в зависимости от времени года?
- В каких городах наблюдаются наиболее высокие уровни загрязнения?
- Как отличаются погодные условия между городами?

### Визуализации

В Power BI используются:

- карта городов;
- графики временной динамики;
- сравнение городов;
- анализ взаимосвязей;
- фильтры и срезы;
- показатели качества воздуха;
- погодные показатели.

---

## Настройка PostgreSQL

Создайте базу данных:

```text
weather_kz
```

Создайте файл `.env` в корне проекта и укажите параметры подключения:

```env
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
DB_NAME=weather_kz
```

> Файл `.env` не должен загружаться в GitHub. Для примера конфигурации используется `.env.example`.
